# Atari Breakout – Assembly Language Game

## Overview
Atari Breakout is an academic group project that recreates the classic brick-breaking game using x86/8086 assembly language.

## Technologies
- x86/8086 Assembly Language
- Assembly interrupts and low-level input/output (where used by the implementation)

## Project Type
Academic group project

## Gameplay
The game is based on the classic Breakout concept:
- Control a paddle to keep the ball in play.
- Hit and break the bricks with the ball.
- Track the game score and remaining lives, if implemented in the submitted version.
